# Caroline Vilas Boas — prévia comercial

Site estático. Abra index.html ou sirva a pasta com `python -m http.server 8000`. Para publicar em previa.taisgb.com.br/carolinevilasboas/, copie index.html, style.css, palette.css e script.js para o diretório correspondente. Não exige build. Prévia marcada noindex,nofollow; retirar somente na publicação oficial autorizada.

As imagens e a fonte são referenciadas por URL pública (dependem de internet); não foram copiadas localmente por indisponibilidade de rede no ambiente. Allo de Josh Puckett, SIL OFL 1.1, https://github.com/joshpuckett/allo. Ícones Lucide via CDN. A marca tipográfica e paleta são propostas, não identidade oficial confirmada. Confirmar autorização de fotografias, contatos e informações antes da publicação. Sem coleta de dados ou formulário. Galeria, fontes, links externos e WhatsApp precisam de verificação em navegador conectado. Sem feed Instagram ao vivo; link para perfil. Avaliação Doctoralia é snapshot de 25/11/2026, não dinâmica.

Fontes: https://carolinevilasboas.net.br/ ; https://www.doctoralia.com.br/perfil/caroline-campos-vilas-boas ; https://allo.joshpuckett.me/ .
